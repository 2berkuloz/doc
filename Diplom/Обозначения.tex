\section*{ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ}

БД -- база данных.

ИС -- информационная система.

ИТ -- информационные технологии. 

КТС -- комплекс технических средств.

ОМТС -- отдел материально-технического снабжения. 

ПО -- программное обеспечение.

РП -- рабочий проект.

СУБД -- система управления базами данных.

ТЗ -- техническое задание.

ТП -- технический проект.

API (Application Programming Interface) -- интерфейс, через который клиент (браузер) обменивается JSON-данными с сервером по протоколу HTTP.

UI (User Interface) – пользовательский интерфейс. 

UX (User Experience) – пользовательский опыт. 

UX/UI Design – дизайн пользовательского опыта и интерфейса. 

DM (Direct Message) – прямое Сообщение. 

PM (Private Message) – личное Сообщение. 

Wireframe – каркасный прототип. 

Mockup – статическое изображение интерфейса с проработанным дизайном (цвета, шрифты, иконки), но без интерактивности.

Prototype – интерактивная модель интерфейса, которая позволяет имитировать взаимодействие пользователя с продуктом. 

GUI (Graphical User Interface) – графический пользовательский интерфейс.
